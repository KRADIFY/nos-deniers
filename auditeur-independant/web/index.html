01

Retrouver la bonne case

Année, mission, programme, action, sous-action, étape budgétaire et AE/CP sont contrôlés séparément. Un chiffre correct placé dans une mauvaise colonne est une anomalie.

02

Refaire les calculs

Le moteur additionne les montants de référence, applique les exclusions et recalcule les variations et l’inflation, avec ses propres formules.

03

Voir ce qui reste incertain

Une case manquante reste manquante. Les écarts entre documents, les contrôles interrompus et les parties non vérifiées sont expliqués dans le rapport.

Ce que signifie un résultat conforme

Le site restitue correctement la référence sur les contrôles terminés. Cela ne prouve pas que toutes les données publiques ont été collectées ni que tous les documents officiels sont exempts d’erreurs.
